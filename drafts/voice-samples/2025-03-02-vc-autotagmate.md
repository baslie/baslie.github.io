# Расширение для Chrome для структурирования промптов

Опубликовал **AutoTagMate** — бесплатное расширение для Chrome для автозакрытия тегов. Удобно использовать в том же ChatGPT, Claude AI и проч., чтобы выделять части промпта отдельными «тегами».

* **Для одного слова**: написал _Текст_, нажал стандартный Tab (можно задать свою комбинацию клавиш) — получил _<Текст></Текст>_ с курсором между _>_ и _<_.
* **Также можно и для фраз**: написал _Какой-то текст_, выделил всю фразу курсором или с помощью клавиатуры, нажал Tab — получил _<Какой-то текст></Какой-то текст>_.
