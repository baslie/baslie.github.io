# Макет сайта на канвасе pen.dev

`design.pen` — макет сайта baslie.github.io в трёх ширинах: **1920** (десктоп), **834** (планшет), **390** (мобильный). Светлая тема.

## Что внутри

| Экран | 1920 | 834 | 390 |
| --- | --- | --- | --- |
| Главная (колонка-визитка + лента «Кейсы и статьи») | ✓ | ✓ | ✓ |
| Модалка контактов (10 карточек на размытом фоне) | ✓ | ✓ | ✓ |
| Страница кейса («Берлога») | ✓ | ✓ | ✓ |
| 404 | ✓ | ✓ | ✓ |

Плюс блок **Library** в левом верхнем углу канваса: цветовые токены и reusable-компоненты.

## Раскладка канваса

- `x = 0` — колонка 1920, `x = 2200` — 834, `x = 3300` — 390.
- Сверху вниз в каждой колонке: главная → модалка → кейс → 404. Над каждым фреймом — текстовая подпись.

## Главная

Вместо бенто-сетки — **колонка-визитка и лента**.

- **1920**: слева липкая колонка 420px на сером фоне (`surface`) с правой границей — фото, имя, описание, три карточки контактов, кружки соцсетей, ссылки, реквизиты. Справа лента: заголовок «Кейсы и статьи» с подписью и управлением (фильтры «Все / Кейсы / Статьи», тема, язык) и сетка карточек в три колонки по 441px.
- **834**: визитка разворачивается в горизонтальный блок на всю ширину — фото и текст в строку, контакты в три колонки, соцсети и ссылки в одной строке. Лента ниже, сетка в две колонки по 375px.
- **390**: визитка целиком вертикальная, контакты друг под другом. Лента в одну колонку по 350px, управление лентой переносится под заголовок.

Тема и язык переехали из `CornerNav` в шапку ленты, поэтому на главной `CornerNav` больше не используется — компонент остался для остальных экранов. Футер с реквизитами тоже переехал — теперь он внизу визитки.

## Компоненты (reusable)

| Компонент | Где используется |
| --- | --- |
| `CategoryBadge` | значок-копирка в углу карточек |
| `BentoCard Desktop` | карточки модалки на ≥1200px (иконка сверху) |
| `BentoCard Row` | карточки модалки на <1200px (иконка + заголовок в строку) |
| `ArticleCard` | карточки в ленте «Кейсы и статьи» |
| `CornerNav Desktop` / `CornerNav Mobile` | логотип + EN + переключатель темы (40px / 32px) |
| `ArticleSiteLink` | оранжевая кнопка-ссылка на сайт внутри кейса |

Правка компонента расходится по всем инстансам; тексты и иконки переопределены через `descendants`.

## Переменные

Цвета вынесены в переменные документа и повторяют `src/styles/input.css`: `card-bg`, `text` (#111827), `text-light` (#F9FAFB), `text-muted` (#6B7280), `link` (#3B82F6), `brand` (#F6522E), `overlay` (#0000004D), бейджи кейса/статьи, цвета иконок сервисов, `radius` (24).

Нейтрали колонки-визитки добавлены отдельно: `surface` (#F4F4F4) — фон визитки, `border` (#E3E3E3) — границы и разделители, `text-subtle` (#9B9B9B) — подписи и надзаголовки.

## Оговорки

- Шрифт сайта — `system-ui` (на Windows это Segoe UI), в макете — **Inter**: ближайший доступный на канвасе. Из-за разницы в ширине глифов переносы строк местами отличаются, поэтому высота длинных колонок не совпадает со скриншотом браузера до пикселя.
- Главная теперь на плоском фоне (белая лента + серая визитка) вместо кадра `public/images/bg.webp` с затемнением. На модалке, кейсе и 404 фон прежний — `bg.webp` вместо фонового видео `public/videos/bg.mp4`.
- Липкость левой колонки на канвасе не показать: колонка нарисована во всю высоту страницы, содержимое прижато к верху.
- Ссылки внутри текста не подсвечены отдельным цветом: на канвасе нет частичного форматирования внутри абзаца. В описании профиля на главной текст оставлен сплошным.
- Ютуб-эмбед в кейсе показан плашкой с иконкой вместо живого плеера.

## Ассеты

Картинки не дублируются: макет ссылается прямо на `../public/images/**` — фон, фото профиля, обложки всех 20 карточек, иконки источников, картинки кейса «Берлога». Если обложку кейса заменят в `public`, макет подхватит её сам.
